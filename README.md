# שעון נוכחות

הדמיית נתונים · תרגיל 1: זמן · עידן עטר · נובמבר 2026

יום שלם בשתי דקות, לפי יומן פעילות שכתבתי בעצמי ולפי זמן המסך שהטלפון מדד, לאורך ארבעה ימים (שני ימי מנוחה ושני ימי עבודה).

השאלה: כמה זמן אני באמת עם הבן שלי, וכמה מהזמן הזה אני בעצם בטלפון.
הממצא: בערך רבע מהזמן שרשמתי כ"זמן עם יותם" עבר עם טלפון ביד, בימי מנוחה כמו בימי עבודה.

**זמן משותף ≠ קשב משותף**
